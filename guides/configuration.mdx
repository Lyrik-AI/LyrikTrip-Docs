AnyAgent 把配置视为服务边界。一个 workspace 声明有哪些 agents、它们能使用哪些能力，以及 server 如何解析 models、tools、skills、MCP servers、credentials 和 sandbox policy。

## Workspace 布局

```text
my-workspace/
  AGENTS.md
  models.yaml
  .anyagent/
    agents/
      main/
        AGENTS.md
        agent.yaml
        mcp.json
    skills/
      example-skill/
        SKILL.md
  plugins/
    demo/
      plugin.json
      plugin.py
      README.md
```

## 根目录文件

| 文件 | 归属 | 用途 |
| --- | --- | --- |
| `AGENTS.md` | Workspace | 人类和 agent 的协作说明。 |
| `models.yaml` | Workspace | workspace 内共享的 model/provider aliases。 |
| `.anyagent/` | AnyAgent | Agent packs、skills 和 MCP 配置。 |
| `plugins/` | Application | 可选 Tool Runtime plugins。生成的示例默认不启用。 |

<Warning>
  不要把明文 API keys 或 bearer tokens 写入 `mcp.json`、`agent.yaml` 或源码仓的 dependency files。请使用 credential references 和 server-side secret stores。
</Warning>

## Agent pack 文件

每个 agent 放在 `.anyagent/agents/<agent_id>/`。

| 文件 | 用途 |
| --- | --- |
| `AGENTS.md` | 注入到该 agent prompt envelope 的行为指令。 |
| `agent.yaml` | Tools、skills、默认模型、sandbox policy、exposure 和 multi-agent spawn 规则。 |
| `mcp.json` | MCP server 连接配置和 credential references。 |

## 最小 agent.yaml

```yaml
exposed: true
model:
  default: fast
tools:
  requested_tool_names:
    - core.web_fetch
skills:
  default_selected: []
sandbox:
  mode: "disabled"
multiagent:
  spawn_allow_agent_ids: ["main"]
```

## Model aliases

Model/provider aliases 放在 workspace 根目录的 `models.yaml`。

```yaml
models:
  fast:
    provider: openai
    model: gpt-4.1-mini
```

请求仍然可以显式传入 `model`。如果请求没有传，server 会用 agent default，通过 `models.yaml` 解析到真实 provider 和模型名。

## MCP servers

`mcp.json` 只放 MCP 连接配置和 credential references。

```json
{
  "mcpServers": {
    "docs": {
      "url": "https://example.com/mcp",
      "transport": "streamable_http",
      "auth": {
        "credential_id": "cred_docs_mcp",
        "ref_kind": "bearer_token",
        "injection": "header:Authorization",
        "format": "Bearer {value}"
      }
    }
  }
}
```

Agent 看到的是 tool surface。Server 负责解析 `credential_id`、注入凭据、应用 policy，并记录 audit data。
