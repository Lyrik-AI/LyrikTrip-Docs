anyagent is a configuration-first Agent Server core and SDK. It starts an OpenAI Responses API-compatible service from workspace files such as `AGENTS.md`, `agent.yaml`, and `mcp.json`, without requiring application teams to write their own server shell.

## What anyagent provides

- A built-in Agent Server with `POST /v1/responses` and streaming events.
- A Python SDK with OpenAI-compatible access and anyagent-specific event helpers.
- Agent packs under `.anyagent/agents/<agent_id>/` for instructions, tools, skills, MCP servers, sandbox policy, and multi-agent boundaries.
- A server-managed security model where agents see resource references, while credentials and tool policy stay behind the server boundary.
- A path from local in-process runtime to external storage, independent Tool Runtime, and production operation commands.
