AnyAgent 是一个**配置即服务**的 Agent Server core + SDK。你可以用 `AGENTS.md`、`agent.yaml`、`mcp.json` 等配置文件启动一个 OpenAI Responses API-compatible 的 Agent Server，而不需要为每个业务应用重复编写服务端壳。

## AnyAgent 提供什么

- 内置 Agent Server：提供 `POST /v1/responses` 与 streaming events。
- Python SDK：保留 OpenAI-compatible client 使用方式，同时提供 AnyAgent 精细事件能力。
- Agent packs：在 `.anyagent/agents/<agent_id>/` 下声明指令、工具、skills、MCP servers、sandbox policy 和 multi-agent 边界。
- Server-managed security：agent 只看到资源引用，credentials、tool policy、audit 和注入逻辑由 server 控制。
- 渐进式生产路径：从本地 in-process runtime 逐步升级到 external storage、独立 Tool Runtime 和 ops commands。
