这条路径适合你想先在本地跑通一个 AnyAgent service：一个 exposed agent、一个生成的 example skill，以及一个可直接请求的 OpenAI-compatible API。

## 前置条件

- Python 3.11 或更新版本。
- 能访问团队使用的 Python package source。
- 一个允许创建 `.anyagent/` 配置目录的工作目录。

## 安装 anyagent

```bash
pip install anyagent
```

如果团队从 Yunxiao Packages PyPI 安装，请通过本地、服务器或 CI/CD secrets 配置 package index。不要把 repository password 写进源码仓的 dependency files。

## 创建 workspace

```bash
anyagent init --workspace ./my-workspace --with-example-skill
anyagent doctor --workspace ./my-workspace
anyagent agent list --workspace ./my-workspace
```

`init` 生成 workspace 结构。`doctor` 检查 agent packs、skills、MCP 配置和常见安全边界问题。`agent list` 展示 exposed agents、default model、requested tools、sandbox mode 和 spawn boundaries。

```text
my-workspace/
  AGENTS.md
  models.yaml
  .anyagent/
    agents/
      main/
        AGENTS.md
        agent.yaml
        mcp.json
    skills/
      example-skill/
        SKILL.md
  plugins/
    demo/
      plugin.json
      plugin.py
      README.md
```

<Note>
  生成的 `plugins/demo/` 是插件示例，不会默认启用。除非你在 agent tool configuration 里显式 request，否则 agent 看不到这个工具。
</Note>

## 启动服务

本地开发优先用：

```bash
anyagent dev --workspace ./my-workspace
```

`dev` 会启动本地 API，并在未配置 key 时使用 development key，同时挂载 Studio。

```text
API:    http://127.0.0.1:8787/v1
Studio: http://127.0.0.1:8787/studio/
```

如果只需要服务进程，用：

```bash
anyagent serve --workspace ./my-workspace --port 8787
```

## 调用 OpenAI-compatible API

把 OpenAI-compatible client 指向本地 base URL，或直接用 `curl`：

```bash
curl http://127.0.0.1:8787/v1/responses \
  -H "Authorization: Bearer anyagent-dev-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "default",
    "input": "Say hello from anyagent."
  }'
```
