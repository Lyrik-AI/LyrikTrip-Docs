Use this flow when you want a local anyagent service with one exposed agent and a generated example skill.

## Prerequisites

- Python 3.11 or newer.
- Access to the package source used by your environment.
- A working directory where anyagent can create `.anyagent/` configuration files.

## Install anyagent

```bash
pip install anyagent
```

If your team installs from Yunxiao Packages PyPI, configure the package index through local, server, or pipeline secrets. Do not commit repository passwords into dependency files.

## Create a workspace

```bash
anyagent init --workspace ./my-workspace --with-example-skill
anyagent doctor --workspace ./my-workspace
anyagent agent list --workspace ./my-workspace
```

`init` creates the workspace layout. `doctor` checks agent packs, skills, MCP configuration, and common security boundary issues. `agent list` shows exposed agents, default models, requested tools, sandbox mode, and spawn boundaries.

```text
my-workspace/
  AGENTS.md
  models.yaml
  .anyagent/
    agents/
      main/
        AGENTS.md
        agent.yaml
        mcp.json
    skills/
      example-skill/
        SKILL.md
  plugins/
    demo/
      plugin.json
      plugin.py
      README.md
```

<Note>
  The generated `plugins/demo/` plugin is an example. It is not enabled by default and does not become visible to agents unless you request it in the agent tool configuration.
</Note>

## Start the server

```bash
anyagent dev --workspace ./my-workspace
```

The development command starts a local API and mounts Studio with a development key if no key is configured.

```text
API:    http://127.0.0.1:8787/v1
Studio: http://127.0.0.1:8787/studio/
```

For a service-only process, use:

```bash
anyagent serve --workspace ./my-workspace --port 8787
```

## Call the OpenAI-compatible API

Point an OpenAI-compatible client at the local base URL:

```bash
curl http://127.0.0.1:8787/v1/responses \
  -H "Authorization: Bearer anyagent-dev-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "default",
    "input": "Say hello from anyagent."
  }'
```
