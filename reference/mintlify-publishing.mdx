AnyAgent 的 Mintlify 发布根目录是公开仓 `Lyrik-AI/LyrikTrip-Docs` 的仓库根目录。

## Dashboard 设置

在 Mintlify dashboard 项目中，将 Git source 配成：

| 设置 | 值 |
| --- | --- |
| Repository | `Lyrik-AI/LyrikTrip-Docs` |
| Branch | 需要发布的分支，通常是 `main` |
| Docs directory | Repository root |
| Config file | `docs.json` |

如果你使用现有项目，例如 `https://app.mintlify.com/loap/loap`，打开它的 Git settings，把仓库连接到 `Lyrik-AI/LyrikTrip-Docs`。

<Info>
  这个仓库本身就是公开文档根目录，因此 Mintlify Git settings 不需要配置 subdirectory。
</Info>

## 本地验证

在公开文档仓根目录运行：

```bash
mint validate
mint broken-links --check-anchors
```

本地预览：

```bash
mint dev --no-open
```

## 维护清单

<Steps>
  <Step title="先更新工程真源">
    行为、配置、contract 或运行方式变化时，先改 AnyAgent 源仓的 `README.md`、`requirements.md`、`todo/*.md`、`docs/**` 或 protocol model。
  </Step>
  <Step title="再更新公开导航">
    新增公开页面后，把页面加入 `docs.json`。不在 navigation 中的页面默认不会进入 sitemap、search 和 MCP results。
  </Step>
  <Step title="本地验证">
    推送前运行 `mint validate` 和 `mint broken-links --check-anchors`。
  </Step>
</Steps>
